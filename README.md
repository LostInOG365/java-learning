### 📖 library-management/
**My main project:** A library management system for managing books and loans.

**Features (implemented/planned):**
- Add, remove, and search for books
- Book information: title, author, ISBN, availability
- Borrowing and returning books with due dates
- Overview of all books
- Database integration (MySQL)

**Technical implementation:**
- Object-oriented design with classes: `Book`, `User`, `Library`
- Collections (ArrayList, HashMap)
- MySQL database connection
- Error handling with try-catch

**Planned extensions:**
- User system with login
- Fee management for late returns
- Reservation system
- Automatic reminders
- Book recommendations based on borrowing history
- Admin dashboard
- Digital resources (e-books, magazines)
- Queue function for popular titles
